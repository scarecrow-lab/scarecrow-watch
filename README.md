# Scarecrow Watch — เว็บไซต์ที่อัปเดตข้อมูลอัตโนมัติ

แดชบอร์ดสาธารณะ ใช้ฟรี แสดงคะแนนความเสี่ยงที่ Scarecrow Lab ประเมิน คู่กับข้อมูลสาธารณะที่ดึงใหม่ทุกวันโดยอัตโนมัติ
โฮสต์ฟรีบน GitHub Pages และอัปเดตด้วย GitHub Actions ไม่ต้องมีเซิร์ฟเวอร์

`signals.json` ตอนแรกมีรายการตั้งต้น 4 รายการที่ Scarecrow คัดมาเอง เมื่อรันครั้งแรกจะถูกแทนด้วยข้อมูลจริง และรายการเก่ากว่า 14 วันจะหลุดออกเอง

## ติดตั้ง (ครั้งเดียว ประมาณ 20 นาที)

1. **สร้าง repository บน GitHub** แบบ Public (GitHub Pages ฟรีสำหรับ repo สาธารณะ) แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ รวมถึงโฟลเดอร์ `.github` และไฟล์ `.nojekyll`
2. **อนุญาตให้ Actions เขียนไฟล์:** ในหน้า Settings ของ repo ส่วน Actions ตั้ง Workflow permissions เป็น "Read and write"
3. **เปิด GitHub Pages:** ในหน้า Settings ส่วน Pages เลือก Deploy from a branch → branch `main` → โฟลเดอร์ `/ (root)` เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`
4. **ขอ appname ของ ReliefWeb:** ReliefWeb API ต้องใช้ appname ที่ได้รับอนุมัติ ขอได้จากหน้าเอกสาร API ของ ReliefWeb จากนั้นใส่เป็น repository secret ชื่อ `RELIEFWEB_APPNAME` (ถ้ายังไม่มี ระบบยังทำงานได้ แค่ไม่มีข้อมูลจาก ReliefWeb และหน้าเว็บจะแสดงว่าแหล่งนี้ดึงไม่สำเร็จ)
5. **รันครั้งแรก:** แท็บ Actions → "Update data" → Run workflow ใช้เวลาประมาณ 2–3 นาที แล้วตรวจ `data/meta.json` ว่าแต่ละแหล่งเป็น `"status": "ok"`

## ตั้งค่าอีเมลติดต่อ

แก้ `data/site.json` เปลี่ยน `CHANGE-ME@example.org` เป็นอีเมลจริงของทีม ส่วน "ข้อเสนอแนะและเรื่องร้องเรียน" จะซ่อนไว้จนกว่าจะเปลี่ยน
เว็บนี้ไม่มีเซิร์ฟเวอร์ ปุ่มจึงแค่เปิดแอปอีเมลของผู้ใช้ ไม่มีการเก็บข้อมูลบนเว็บ สำหรับเรื่องอ่อนไหว ควรเตรียมช่องทางที่ปลอดภัยกว่า เช่น อีเมลเข้ารหัสหรือ Signal ไว้ด้วย

## ดูบนเครื่องตัวเอง

เปิดไฟล์ `index.html` ตรงๆ จะโหลดข้อมูลไม่ได้ ต้องเปิดผ่านเซิร์ฟเวอร์:

```
python3 -m http.server 8000
```

แล้วเข้า http://localhost:8000

## ชั้นประเมิน PREVENT

ดัดแปลงจากกรอบ PREVENT ของ AIPG ทุกตัวชี้วัดให้คะแนน 1–5 คะแนนหมวด = ค่าเฉลี่ยของตัวชี้วัดในหมวด ดัชนีเชิงโครงสร้าง = ค่าเฉลี่ยของ 6 หมวด (P, R, E, V, E, N) ส่วนหมวด T แสดงเป็นธงเตือนและไม่นำไปเฉลี่ย
ตัวชี้วัดมีสามแบบ: `lab` (Lab ให้คะแนนเองใน `prevent.json`), `auto` (ดึงจากธนาคารโลกทุกวันแล้วตัดคะแนนตาม `thresholds`), `derived` (ความรุนแรงในประเทศเพื่อนบ้าน คำนวณจากคะแนนความขัดแย้งของ Lab)
คะแนนแบบ `lab` ชุดแรกเป็นร่างที่ Claude จัดทำ หน้าเว็บจะขึ้นแถบ "ฉบับร่าง" จนกว่าจะเปลี่ยน `"status"` เป็น `"reviewed"`

## อัปเดตอัตโนมัติแบบตรวจเฉพาะข้อยกเว้น

- ตัวชี้วัดจากธนาคารโลก V-Dem (ผ่าน Our World in Data) และ UCDP อัปเดตเองทุกวัน
- ถ้าคะแนนขยับไม่เกิน 1 ระดับ เผยแพร่ทันที ถ้าขยับ 2 ระดับขึ้นไป ระบบพักไว้ใน `auto_review.json` และคงคะแนนเดิมบนเว็บ จนกว่า Lab จะอนุมัติใน Review Room แล้วอัปโหลด `auto_approvals.json`
- UCDP ต้องใช้ token ฟรี ใส่เป็น repository secret ชื่อ `UCDP_TOKEN` ระหว่างที่ยังไม่มี ระบบใช้คะแนน Lab แทน
- Factbook: ตัวเลขจากธนาคารโลกแสดงแทนข้อความที่ Lab พิมพ์ไว้โดยอัตโนมัติ ส่วนผู้นำประเทศ ระบบตรวจจาก Wikidata ทุกวัน ถ้าเปลี่ยนจะพักไว้ใน Review Room ให้ Lab ยืนยันและเขียนข้อความเอง ไม่เผยแพร่อัตโนมัติ
- การเลือกตั้งที่ Lab บันทึกใน `prevent.json` จะขึ้นเป็นตัวกระตุ้นเองตั้งแต่ 180 วันก่อนจนถึง 30 วันหลังวันเลือกตั้ง
- ความรุนแรงในประเทศเพื่อนบ้านคำนวณจากจุดอ้างอิงชายแดนโดยประมาณใน `border_points` ปรับได้

## อัปเดตการประเมินของ Lab

แก้ `data/assessments.json` แล้ว commit คะแนนจะเปลี่ยนเฉพาะตอนที่ Lab แก้ไฟล์นี้เท่านั้น สคริปต์อัตโนมัติไม่แตะไฟล์นี้
อย่าลืมเปลี่ยนค่า `"reviewed"` เป็นวันที่ทบทวน

**กติกา Data firewall:** ใส่ในไฟล์นี้ได้เฉพาะข้อค้นพบที่ Lab ยืนยันและเผยแพร่แล้ว พร้อมลิงก์แหล่งสาธารณะ ห้ามใส่เบาะแส คำให้การพยาน หรือข้อมูลจากแฟ้มคดี เพราะทุกอย่างใน repo สาธารณะมีคนอ่านได้ รวมถึงประวัติการแก้ไขย้อนหลัง

## เมื่อแหล่งข้อมูลล่ม

ถ้าแหล่งใดดึงไม่สำเร็จ สคริปต์เก็บข้อมูลเดิมไว้ บันทึกข้อผิดพลาดใน `meta.json` และหน้าเว็บจะขึ้นจุดสีแดงที่แหล่งนั้น ถ้าข้อมูลเก่ากว่า 48 ชั่วโมงจะขึ้นจุดสีส้ม

## สิ่งที่ต้องตรวจในการรันจริงครั้งแรก

สคริปต์นี้ทดสอบกับข้อมูลจำลองแล้ว แต่ยังไม่เคยเรียก API จริง เพราะเครื่องที่ใช้เขียนไม่มีอินเทอร์เน็ต สิ่งที่อาจต้องปรับ:

- **UNHCR:** ชื่อพารามิเตอร์และรูปแบบตัวเลขที่ API ส่งกลับ ถ้าได้ตัวเลขผิดหรือว่าง ดู log ใน Actions
- **ReliefWeb:** เงื่อนไขของ appname และรูปแบบตัวกรอง
- **GDELT:** จำกัดความถี่ (สคริปต์เว้น 6 วินาทีต่อคำขอแล้ว) และอาจมีข่าวที่ไม่เกี่ยวข้องปนมา ปรับคำค้นได้ที่ `GDELT_TERMS`

## ลิขสิทธิ์ข้อมูล

ข้อมูลแต่ละแหล่งแสดงตามเงื่อนไขของผู้ให้บริการ ตรวจเงื่อนไขล่าสุดก่อนเปิดใช้งานจริง
ข้อมูล ACLED ไม่ได้ดึงอัตโนมัติ เพราะต้องลงทะเบียนและมีเงื่อนไขการใช้เชิงพาณิชย์ ใช้อ้างอิงในหลักฐานของ Lab แทน
